# 浙江师范大学学生学业领航智能体系统 — 前端Demo设计开发报告

## 一、项目概述

### 1.1 项目名称
浙江师范大学学生学业领航智能体系统 — 前端Demo（一期 + 二期 + 三期）

### 1.2 项目背景
为响应国家教育数字化战略行动，浙江师范大学拟建设以"学业画像为核心、智能体为引擎、四路径发展为导向、预警干预为保障"的学生学业领航智能体系统。本前端Demo覆盖系统三期建设的完整功能视图，通过可视化交互原型展示全链路核心功能，为正式开发提供设计验证与客户沟通基础。

### 1.3 Demo目标
- 验证三期全功能链路的用户体验与交互流程
- 呈现符合浙师大品牌调性的视觉设计体系
- 为各期项目验收、推广与招标提供可演示的交互原型
- 为后续真实系统开发提供界面与交互的参考规范

### 1.4 建设阶段划分

| 阶段 | 目标 | 前端Demo范围 |
|------|------|-------------|
| **一期**（已完成） | 基础能力搭建 | 登录、学生5页、教师3页，纯静态Mock |
| **二期**（当前） | 核心能力完善 | 新增四路径引导、橙/红预警、干预回填、专业负责人端、院领导端 |
| **三期**（规划） | 能力扩展演进 | 知识点图谱、学习资源推送、同辈孪生推荐、学业沙盘推演 |

## 二、目标用户与角色分析

### 2.1 用户角色

| 角色 | 使用场景 | 核心诉求 | 技术素养 | 引入阶段 |
|------|---------|---------|---------|---------|
| **学生** | 日常学业查询、学期体检、发展路径规划 | 了解自身定位、获取行动建议 | 高（数字原生代） | 一期 |
| **班主任/辅导员** | 班级管理、预警干预、个别辅导 | 快速定位重点关注学生 | 中 | 一期 |
| **专业负责人** | 专业建设、课程评估 | 识别课程问题、优化培养方案 | 中-高 | 二期 |
| **院领导** | 全局决策、资源配置 | 掌握全院学业态势 | 中 | 二期 |

### 2.2 用户旅程（全期范围）

**学生端核心旅程**：
```
登录 → 首页仪表盘（学业概览）
     → AI智能体对话（学业查询/问询建议）
     → 学业画像（五维雷达图）
     → 学业体检报告（学期推送）
     → 预警通知查看
     → 四路径发展引导（二期）
     → 关键帧推送通知（二期）
     → 学习资源推送（三期）
     → 学业沙盘推演（三期）
```

**教师端（班主任/辅导员）旅程**：
```
登录 → 班级画像驾驶舱（KPI概览）
     → 预警学生清单（黄色→橙色→红色）
     → 学生个体画像查阅
     → 预警处理 + 干预回填（二期）
```

**专业负责人端旅程（二期）**：
```
登录 → 专业学业态势概览
     → 课程达成度热力图
     → 培养方案偏差分析
     → 跨年级学业质量追踪
```

**院领导端旅程（二期）**：
```
登录 → 全院学业质量指数
     → 各专业健康度对比
     → 预警分布与干预响应率
     → 人才培养方案执行效果
```

## 三、技术选型方案

### 3.1 前端技术栈（实际使用，与原规划有差异）

| 技术 | 实际版本 | 说明 |
|------|---------|------|
| **Vue 3** | ^3.4 | 组合式API + `<script setup lang="ts">` |
| **TypeScript** | ^5.4 | 严格模式，类型集中在 `src/types/index.ts` |
| **Element Plus** | ^2.14+ | 图标全局注册，覆盖 `--el-color-primary` |
| **Tailwind CSS** | **v4**（非v3） | `@import "tailwindcss"` + `@theme {}` 块，**无 tailwind.config.js** |
| **ECharts 5/6** | ^5.5+ | 直接 `echarts.init()`，**不用 vue-echarts wrapper** |
| **Vite** | ^8 | 开发服务器 http://localhost:5175 |
| **Pinia** | ^2.1 | 当前仅 `stores/auth.ts`，二期需扩展 |
| **Vue Router** | ^4.3 | 嵌套路由，已完成一期路由结构 |

> **Tailwind v4 关键差异**：不使用 `tailwind.config.js`，所有自定义颜色 token 写在 `src/style.css` 的 `@theme {}` 块，变量格式为 `--color-zjnu-blue-500: #2A4D99`。自定义颜色不自动生成 bg/text utility class，需手写 scoped CSS。

### 3.2 可视化技术

| 场景 | 技术选择 |
|------|---------|
| 学业画像雷达图 | ECharts Radar |
| GPA 趋势折线图 | ECharts Line + area gradient |
| 预警分布饼图 | ECharts Pie |
| 班级群像对比 | ECharts Radar（多系列） |
| 课程达成度热力图（二期） | ECharts Heatmap |

## 五、视觉设计规范

### 5.1 设计理念

**Minimal Tech + Liquid Glass** — 极简科技，液态玻璃质感。教育机构的稳重可信与智能系统的现代感并存。

| 维度 | 设计表达 |
|------|---------|
| 教育属性 | 稳重、可信、学术感 |
| 智能属性 | 科技感、数据驱动、AI赋能 |
| 人文关怀 | 温暖、陪伴、不冰冷 |
| 年轻活力 | 现代、简洁、有呼吸感 |

### 5.2 色彩体系（实际实现值）

| 色值 | 用途 | 语义 |
|------|------|------|
| `#2A4D99` 浙师大蓝 | 主色：导航 active、按钮、accent 条 | 专业、可信 |
| `#5ed29c` 成长绿 | 辅色：正常状态、通过、正向趋势 | 健康、成长 |
| `#ffb27e` 活力橙 | 强调色：中等风险、进度提示 | 关注、活力 |
| `#f09a4e` 深橙 | 橙色预警 | 警示 |
| `#e04538` 预警红 | 红色预警、严重错误 | 紧急、干预 |
| `#f5a623` 黄色 | 黄色预警 | 关注 |
| `#f6f8fb` 浅灰蓝 | 页面底色 | 清爽、层次 |
| `#0a1329` 深海蓝 | 登录左面板背景 | 沉浸感 |
| `#0e1a32 → #101d3e` | 侧边栏渐变背景 | 专业深色 |

### 5.3 字体规范

**字体栈**（已在 `src/style.css` 配置）：
```
'Plus Jakarta Sans', 'PingFang SC', 'Hiragino Sans GB', 'Microsoft YaHei', system-ui, sans-serif
```
Latin 字符使用 Plus Jakarta Sans（Google Fonts），中文降级系统字体。

**字号层级**：
- 11–11.5px：辅助信息、徽章、label
- 12–13px：正文、表格、描述
- 14px：卡片标题、导航项
- 20px：卡片数值标题
- 24–28px：KPI 大数字
- 26px：页面大标题

### 5.4 组件风格

- **卡片**：`border-radius: 14px`，白色背景，`border: 1px solid #edf0f6`，多层阴影 + hover translateY(-2px)
- **KPI 卡片**：顶部 3px accent 条（`::before`），`--accent` / `--tint` CSS 自定义属性驱动颜色变体
- **侧边栏**：深色渐变背景，active 项左侧 3px 蓝色 accent 条（cubic-bezier 弹性动画）
- **按钮**：`linear-gradient(135deg, #2A4D99, #1d3670)`，hover translateY(-1px) + 加深阴影
- **输入框**：`border-radius: 10px`，覆盖 Element Plus 默认 radius
- **预警徽章**：三色 Tag（黄/橙/红），色值语义对应三级预警

### 8.3 工程规范要点

1. **Tailwind v4**：无 config 文件，token 全在 `src/style.css` 的 `@theme {}` 块
2. **ECharts**：直接 `import * as echarts from 'echarts'`，不用 wrapper，`onBeforeUnmount` 必须 `dispose()`
3. **多行字符串 Mock**：必须用模板字面量（反引号），单引号多行会报 `Unterminated string`
4. **静态资源**：放 `public/`，以 `/filename` 路径引用；深色背景水印用 `mix-blend-mode: screen` + `filter: invert(1)`
5. **组件样式**：优先 `<style scoped>`；CSS 自定义属性（`--accent`、`--tint`）在 scoped 内对 `::before` 有效

## 十一、风险与应对

| 风险 | 影响 | 概率 | 应对策略 |
|------|------|------|---------|
| 新角色 Layout 样式不一致 | 体验割裂 | 低 | 从 TeacherLayout 复制底板，保持同一套 CSS 变量体系 |

| 沙盘推演"预测"缺乏说服力 | 演示效果差 | 中 | 加免责提示，重点强调交互体验，而非预测精度 |
| 三期功能开发量大 | 工期超出 | 中 | 三期部分页面可先做占位卡片（"功能开发中"），确保路由存在即可 |

| Element Plus + Tailwind v4 样式冲突 | 样式异常 | 低 | 已在 style.css 处理主要冲突，新组件优先 scoped CSS |
