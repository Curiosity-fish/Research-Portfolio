#### Step 32：沙盘预测逻辑（纯前端简单线性模型）

```typescript
// src/utils/sandboxPredictor.ts
function predictGPA(params: SandboxParams, baseGPA: number): PredictionResult {
  let delta = 0
  delta += (params.credits - 16) * -0.02         // 学分越多压力越大
  delta += (params.difficulty === 'hard') ? -0.1 : (params.difficulty === 'easy') ? 0.05 : 0
  delta += (params.studyHours - 10) * 0.01        // 自习时长正向
  delta += params.hasActivities ? -0.05 : 0       // 课外活动轻微负向
  return { gpa: Math.min(4.0, Math.max(1.5, baseGPA + delta)), ... }
}
```

响应式：用 Vue `computed` 监听参数变化，实时更新预测结果，无需按钮确认。

## 七、工程规范检查清单（开发前必读）

### Tailwind v4 关键差异
- [ ] **无** `tailwind.config.js`，自定义颜色写在 `src/style.css` 的 `@theme {}` 块
- [ ] 自定义颜色不生成 `bg-zjnu-blue-500` 等 utility，需手写 scoped CSS
- [ ] `@theme {}` 中颜色格式：`--color-zjnu-blue-500: #2A4D99`

### ECharts 使用规范
- [ ] `import * as echarts from 'echarts'`，不用 vue-echarts wrapper
- [ ] `onBeforeUnmount(() => { chart?.dispose() })` 必须
- [ ] tooltip 覆盖：`extraCssText: 'border-radius: 10px; ...'`
- [ ] area gradient：`new echarts.graphic.LinearGradient(0, 0, 0, 1, [...])`

### Mock 数据规范
- [ ] 多行字符串必须用模板字面量（反引号），不能用单引号换行
- [ ] 使用工厂函数生成批量数据，带 `seed` 参数
- [ ] 二期起按角色拆分：考虑将 `mock/data.ts` 拆为 `student.ts`、`teacher.ts`、`department.ts`

### 静态资源规范
- [ ] 图片放 `public/`，以 `/filename` 引用
- [ ] `<img>` 必须有 `alt` 属性、`max-width: 100%`、`object-fit: contain`
- [ ] 深色背景水印：`mix-blend-mode: screen` + `filter: invert(1)` （非 `grayscale + brightness`）

### 组件样式规范
- [ ] 优先 `<style scoped>`
