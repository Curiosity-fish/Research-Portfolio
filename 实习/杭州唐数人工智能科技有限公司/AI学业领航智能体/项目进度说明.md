# Academic Navigation 项目进度说明

**更新时间：** 2026-08-13
**项目状态：** 前后端已对接完成，业务功能已跑通真实数据，AI 对话支持 Dify/E-Agent 直连与 Mock 兜底

---

## 一、项目概述

Academic Navigation 是面向高校的智能学业导航系统（浙师大），为学生、班主任、任课教师、系主任、院领导提供差异化的学业管理和数据分析功能。当前前端五端页面已全部接入真实后端 API（Spring Boot + MySQL），数据实时读库，不再是 Mock 原型。

**技术栈：**
- 前端：Vue 3.5 + TypeScript + Vite 8
- UI 组件库：Element Plus 2.14
- 图表库：ECharts 6 + vue-echarts 8
- 状态管理：Pinia 3（auth + alerts 两个 store）
- 样式：Tailwind CSS 4 + Scoped CSS
- 后端：Spring Boot 3.2.5 + MyBatis-Plus + MySQL + Flyway（迁移至 V7）

## 三、AI 智能体配置

**配置来源：** 前端静态配置 `src/mock/agents.ts`（14 个独立智能体）

**各角色智能体数量：**
- 学生端：8 个
- 班主任端：2 个（与任课教师共享）
- 任课老师端：2 个（与班主任共享）
- 系主任端：2 个（独立版本）
- 院领导端：2 个

**总计：** 14 个独立智能体

| 智能体 | 分类 | 适用角色 | 核心功能 |
|--------|------|---------|---------|
| AI 校策知询 | 政策权益 | student | 奖助学金、助学贷款、创业补贴、就业优惠、落户政策解读 |
| AI 人生规划 | 核心服务 | student | 长期职业发展与人生目标规划，考研/留学/就业决策 |
| AI 学业顾问 | 核心服务 | student | 学业咨询、成绩查询、GPA 分析、选课建议 |
| AI 就业助手 | 就业发展 | student | 技能匹配、简历优化、面试准备、职业路径规划 |
| AI 考研助手 | 升学规划 | student | 院校匹配、竞争力评估、备考时间线 |
| AI 留学助手 | 升学规划 | student | 海外院校推荐、申请材料优化、软背景提升 |
| AI 考编助手 | 考公考编 | student | 事业单位岗位匹配、职测辅导 |
| AI 考公助手 | 考公考编 | student | 公务员考试规划、岗位匹配、行测申论辅导 |
| 学情分析 | 班级学情 | teacher / course_teacher | 班级学情分析、高风险学生识别 |
| 育心导学 | 教育引导 | teacher / course_teacher | 心理健康评估、谈心话术、情绪预警 |
| 学情分析 | 学情管理 | department | 专业级学情分析（系主任版） |
| 育心导学 | 教育引导 | department | 教育引导（系主任版） |
| AI 课程健康度诊断 | 学情管理 | dean | 全院课程质量评估、问题课程识别 |
| AI 跨专业对比分析 | 质量监控 | dean | 各专业横向对比、异常低位专业识别 |

**对话实现（AgentChat.vue）：**
1. **Dify 流式 API**（SSE）：配置 `externalApi.type = 'dify'` 的智能体走 `/v1/chat-messages`，支持多轮 `conversation_id`、`<think>` 思考块过滤；
2. **E-Agent API**：配置 `externalApi.type = 'eagent'` 的智能体走 `/api/v2/assistant/chat/completions`；
3. **Mock 兜底**：无外部 API 配置或调用失败时，返回 `getMockResponse()` 本地回复。

> 注意：当前 baseUrl/assistantId 为演示配置，接入真实服务需替换为实际地址与密钥。

## 五、核心实现

### 5.1 路由与守卫

**文件：** `src/router/index.ts`

- `/login` 登录页
- `/student/*`（6 个页面）、`/teacher/*`（7 个页面）、`/course-teacher/*`（4 个页面）、`/department/*`（5 个页面）、`/dean/*`（4 个页面）
- 全局 `beforeEach` 守卫：无 token 一律跳 `/login`；刷新后调 `/auth/me` 恢复登录态

### 5.2 状态管理

- `src/stores/auth.ts`：登录态 + 角色跳转（`routeMap`），localStorage 持久化
- `src/stores/alerts.ts`：预警未读数（布局角标）

### 5.3 请求封装

- `src/utils/request.ts`：Axios 实例（`baseURL: '/api'`、超时 10s、自动附加 Bearer Token、401 跳登录、code≠200 统一报错）
- `src/api/index.ts`：约 30 个类型化接口函数

### 5.4 图表渲染

- ECharts 6，所有图表 `onMounted` 初始化、`onBeforeUnmount` 销毁
- 类型：折线图（GPA 趋势）、柱状图（专业对比）、雷达图（五维画像）、热力图（课程）、环形图等

### 5.5 布局系统

- 五端独立 Layout：`StudentLayout` / `TeacherLayout` / `CourseTeacherLayout` / `DepartmentLayout` / `DeanLayout`
- 结构：顶部 Header（Logo + 用户信息 + 预警角标 + 退出）+ 左侧导航 + 主内容区
- 共享组件：KpiCard、RadarChart、WarningBadge、AiInsightPanel、PathCard、MilestoneTimeline、JobCard、InterventionForm、HealthCard、EmptyState、chat/ChatMessage、chat/QuickQuestion 等

## 七、已知问题与限制

1. **智能体对话为演示配置**：Dify/E-Agent 地址与密钥未接入真实服务，无配置时回退 Mock 回复
2. **智能体数据非后端驱动**：列表、用量统计（usageCount）为前端静态值，未做集中管理与真实统计
3. **JWT 黑名单降级**：Redis 未启用时黑名单为内存实现，重启失效
4. **校方数据源未启用**：当前数据来自本地 MySQL 种子数据（V3–V7），校方 API 接入待接口文档
5. **GPA 沙盘功能下线**：`sandboxPredictor.ts` 算法保留，页面未挂载
6. **无 token 刷新机制**：token 过期（24h）后需重新登录
7. **预警分页已实现**，但大数据量渲染（如 500+ 学生列表）未做虚拟滚动

## 八、本地启动

**后端**
1. 确保 MySQL 已启动，配置见 `academic-navigation-backend/src/main/resources/application-dev.yml`
2. Flyway 自动执行 V1–V7 迁移并写入种子数据
3. `mvn spring-boot:run`（8080 端口），Swagger：`http://localhost:8080/swagger-ui.html`

**前端**
1. `cd academic-navigation-demo && npm install`
2. `npm run dev`（5173 端口，`/api` 代理到 8080）
