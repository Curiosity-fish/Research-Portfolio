# 大学生人生规划方法论

## 1. 核心原则

1. 先诊断，再选择：先看现状、优势、约束和风险，再选择路径。
2. 方向比速度重要：大一大二重点探索，大三大四重点收敛和执行。
3. 动态调整：人生规划不是一次确定终身，应每学期复盘一次。
4. 数据优先：GPA、画像、预警、课程数据可用时，先引用数据，不重复提问。
5. 事实与建议分离：明确哪些是客观数据，哪些是推断，哪些是建议。

## 2. 人生规划五步法

### 第一步：了解自己

- 学业现状：GPA、排名、学分、挂科、预警。
- 能力画像：学业成绩、实践能力、综合素质、人文素养、身心健康。
- 兴趣与价值：喜欢解决什么问题，愿意接受什么工作节奏，看重收入、稳定、成长还是自主。
- 约束条件：家庭经济、地域偏好、健康、备考时间、专业可迁移性。

### 第二步：打开选项

常见路径：

- 考研深造
- 出国留学
- 直接就业
- 国考公务员
- 事业单位考编
- 先就业再深造
- 创业或自由职业
- 教师等专业对口方向

不要在一开始只给一个答案，通常先保留 2-3 个可行方向。

### 第三步：做证据评估

每个方向至少看四个维度：

1. 匹配度：当前画像与该方向要求的差距。
2. 成本：时间、经济、机会成本。
3. 成功率：结合 GPA、竞争强度、历史经验。
4. 可逆性：如果中途改变，损失有多大。

### 第四步：形成主路径与备选路径

- 主路径：投入 60%-70% 精力。
- 备选路径：保留 20%-30% 精力，设定触发条件。
- 止损条件：例如“两次备考未达目标，即切换就业”。

### 第五步：拆成可执行里程碑

每个目标应包含：

- 本学期的 1-3 个关键动作
- 寒暑假的关键动作
- 一个可观察的验证指标
- 一次定期复盘时间

## 3. 输出建议格式

1. 一句话判断
2. 当前关键事实
3. 2-3 个可行方向及匹配度
4. 推荐主路径和备选路径
5. 未来 3 个月行动清单
6. 需要补充确认的问题，最多 3 个

## 4. 注意事项

- 不把学生简单标签化。
- 不夸大 GPA、竞赛或某个证书的作用。
- 不替学生做最终决定，给决策依据。
- 对心理、健康、经济困难等问题保持敏感。
- 涉及考试、分数线、政策时，提示学生以学校官方发布为准。
