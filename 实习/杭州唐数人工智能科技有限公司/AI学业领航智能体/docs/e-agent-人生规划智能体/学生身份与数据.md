# 学生身份与成绩数据说明

## 为什么 E-Agent 发布页看不到学生成绩

E-Agent 的公开分享页 / iframe 运行在 E-Agent 服务器上，它不知道学校前端的登录身份。

```text
错误链路：
学生前端(已登录)
  -> iframe 打开 E-Agent 分享页
  -> E-Agent 工具调用后端
  -> 后端没有学生 JWT
  -> 返回未登录 / 无数据
```

E-Agent 不会自动去学校前端读取学生数据。

## 当前推荐链路

```text
学生前端(已登录，带 JWT)
  -> 前端直接读取 /api/student/dashboard、/profile、/development/paths
  -> 把学生上下文注入到发给 E-Agent 的消息里
  -> E-Agent 用上下文进行规划和问答
```

前端已经实现：

- 每次提问前自动获取当前学生的成绩、画像、发展路径。
- 把这些数据作为 `system` 上下文传给 E-Agent。
- 每次请求携带完整历史消息，所以可以连续多轮提问。

## E-Agent 侧要求

1. 使用“助手”类型，不要用固定两轮的工作流。
2. 助手可以不配置数据库/API 工具，因为学生数据已经由前端注入。
3. 在 `agents.ts` 中确认 `externalApi.assistantId` 是当前 E-Agent 助手的 ID。

## 使用分享链接时需要注意

你提供的分享链接是：

```text
http://localhost:3001/workspace/share/IWhc8a17ZoCo8wzAIxqXEj5kC0_A_Ezf
```

它适合直接 iframe 嵌入，但 E-Agent 分享页无法自动读取学校前端的登录信息。

如果要在学校前端里自动获取学生成绩，需要走 E-Agent API v2。当前 E-Agent 后端没有配置：

```text
EAGENT_API_KEY
```

所以 API v2 会返回：

```text
API v2 not configured. Set EAGENT_API_KEY env variable.
```

需要由 E-Agent 管理员在服务器配置该环境变量，并在 `agents.ts` 中填入同一个 `apiKey`：

```ts
externalApi: {
  type: 'eagent',
  baseUrl: 'http://localhost:3001',
  assistantId: 'IWhc8a17ZoCo8wzAIxqXEj5kC0_A_Ezf',
  apiKey: '你的 EAGENT_API_KEY',
}
```

前端已经自动添加：

```text
X-API-Key: <apiKey>
```

## 重复回答修复

重复回答通常是 E-Agent 里同时开了：

- “助手”节点的“将输出结果展示在会话中”。
- 后面又接了一个 `output` 节点。

两者都会输出，所以会看到两遍。

建议：

- 中间节点关闭“将输出结果展示在会话中”。
- 只保留最终的 `output` 节点输出。

## 有限轮次修复

“只能输入两次问题”通常是工作流里有固定两个 `input` 节点，流程结束后不再接收输入。

如果目标是连续对话，应使用 E-Agent 的“助手”，而不是“工作流”。助手会维护历史上下文，支持持续追问。
