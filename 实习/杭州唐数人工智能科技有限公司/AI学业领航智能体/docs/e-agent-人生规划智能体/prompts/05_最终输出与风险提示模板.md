# 最终输出与风险提示模板

## 正常输出

直接输出主规划师的最终结果：

```text
{{#agent/final_plan#}}
```

## 高风险输出

当学生表达明显心理危机、自伤、自杀念头，或学业与家庭危机叠加时，使用以下模板：

```markdown
我听到你现在很不容易，谢谢你愿意告诉我。

眼下最优先的不是继续做规划，而是先让自己得到稳定支持。建议你尽快联系：

1. 班主任或辅导员
2. 学校心理健康教育中心
3. 校医院或信任的老师

如果现在感到无法承受，请优先联系可立即提供帮助的人，并尽量不独处。

在获得实际支持后，我们可以再从短期、低压力的小目标开始，逐步恢复节奏。专业诊断和治疗需要由专业机构完成，我不能替代。
```

## 输出禁止项

- 不诊断疾病。
- 不保证“很快会好”。
- 不鼓励隐瞒、拖延或独自硬扛。
- 不把危机归因为“不够努力”。
