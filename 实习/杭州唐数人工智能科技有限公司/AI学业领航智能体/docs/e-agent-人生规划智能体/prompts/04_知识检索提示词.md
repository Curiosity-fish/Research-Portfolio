# 知识检索节点提示词

## `knowledge_retriever` 改写原则

当学生问题很长时，把问题改写成 1-2 个检索意图：

```text
用户问题：{{#input/user_input#}}

请从人生规划方法论、路径阶段任务、决策框架和学校政策中，检索最相关的内容。
检索重点：
1. 用户当前年级对应的阶段任务。
2. 用户提到的路径所需的判断条件。
3. 相关学业与就业政策。
```

## `qa_retriever` 安全检索

```text
用户问题：{{#input/user_input#}}
```

用于检查用户是否存在心理、学业、家庭等风险信号，相似度阈值建议 0.80。

## 检索结果使用规则

- 只引用与当前问题直接相关的内容。
- 多个来源冲突时，分别列出冲突点。
- 检索结果为空时，不要编造知识。
- 政策类内容要标注“以官方最新通知为准”。
