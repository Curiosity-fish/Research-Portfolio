# 数据查询提示词

## SQL Agent 工具规则

1. 使用自然语言精确描述查询需求，把该描述作为 `query` 参数调用 `sqlagent`。
2. 一个查询需求只做一次调用；多个需求分开调用。
3. 先查最小范围，再决定是否需要更多数据。
4. 查询必须带上当前学生学号：`{{#start/student_no#}}`。
5. 禁止查询 `t_user` 的密码字段。
6. 如果数据库不可用，不要假装拿到数据。

## 优先查询顺序

1. `v_agent_student_profile`
2. `v_agent_development_snapshot`
3. `v_agent_gpa_trend`
4. `v_agent_recent_alerts`
5. `v_agent_recent_grades`
6. `v_agent_major_plan`
7. `v_agent_jobs`
8. `v_agent_schools`

## 示例自然语言查询

```text
查询学号 {{#start/student_no#}} 的当前学生档案
```

```text
查询学号 {{#start/student_no#}} 最近 5 个学期的 GPA、排名和专业平均 GPA
```

```text
查询学号 {{#start/student_no#}} 最近学期的五维画像分数
```

```text
查询学号 {{#start/student_no#}} 状态为 pending 或 processing 的最近 10 条预警
```

```text
查询学号 {{#start/student_no#}} 近两年的 failed 或 retake 课程及成绩
```

```text
查询考研院校，按 match_score 从高到低取 9 条
```

```text
查询留学院校，按 match_score 从高到低取 9 条
```

```text
查询适合该专业的就业岗位，按 match_score 从高到低取 15 条
```

## API 工具规则

- 每个工具调用都要先判断当前问题是否真的需要该数据。
- 先调用一个综合接口，再按需补充，避免一次性调用全部接口。
- API 返回异常时，向用户说明“数据服务暂时不可用”，并继续用知识库和用户陈述给出非数据型建议。
