# 条件分支与人工转介

## JSON 无法直接取字段时的 Code 节点

将 LLM 输出 `answer_json` 作为入参。E-Agent 若运行 Python 代码节点，可使用：

```python
import json

def main(answer_json: str) -> dict:
    fallback = {
        "route": "refer",
        "display_answer": (
            "抱歉，我暂时无法从已接入的《浙江工商大学学生手册（2025 汇编）》中"
            "可靠核实这个问题。建议联系所在学院教务办或对应职能部门确认，"
            "并以学校最新通知为准。"
        )
    }
    try:
        data = json.loads(answer_json or "{}")
        route = data.get("route")
        content = data.get("display_answer")
        if route not in {"answer", "clarify", "refer"} or not isinstance(content, str) or not content.strip():
            return fallback
        return {"route": route, "display_answer": content.strip()}
    except (TypeError, json.JSONDecodeError):
        return fallback
```

出参：`route`、`display_answer`。条件节点以 `route` 连接 `answer`、`clarify`、`refer` 三条边。

## 必须转介的情况

- 用户不是浙江工商大学全日制普通本科生，或问研究生、招生、校外实时政策。
- 要求确认本学期具体日期、金额、材料、名单、审批状态或办理入口。
- 证据未命中、存在矛盾，或没有可定位的制度条款。
- 需要学校作出的个案决定，例如处分认定、转专业审批、奖助资格认定、退学处理。
- 用户提供或要求处理身份证号、银行卡、病历、家庭收入证明等敏感资料。

## 转介表达模板

```markdown
我目前只能依据已接入的《浙江工商大学学生手册（2025 汇编）》说明一般规则，无法确认你的具体办理结果或最新安排。

建议你联系【所在学院教务办 / 教务处 / 学生处 / 学生资助中心】中与事项对应的部门，核实本学期的办理时间、材料和审批要求。请以学校及相关部门最新通知为准。
```
