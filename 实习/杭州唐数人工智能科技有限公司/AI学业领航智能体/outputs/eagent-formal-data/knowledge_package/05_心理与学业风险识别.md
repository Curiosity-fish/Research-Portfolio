# 心理与学业风险识别

## 1. 需要关注的心理信号

- 长期情绪低落、兴趣明显减退。
- 睡眠或食欲持续异常。
- 表达“没有意义”“不想继续”等无望感。
- 明显回避社交、上课和日常活动。
- 提到自伤、自杀或不想活。
- 对学习、家庭或人际压力表现出持续恐慌。

## 2. 需要关注的学业风险信号

- GPA 持续下降或多个学期明显偏低。
- 多门课程挂科、长期缺勤。
- 放弃提交作业、逃避考试。
- 对学习目标和能力极度否定。
- 经济困难、家庭变故与学业压力叠加。

## 3. 智能体的处理边界

必须做到：

- 使用平静、明确、不评判的语言。
- 先表达理解和关心。
- 不诊断心理疾病，不保证“一定会好”。
- 不把高风险问题简单转化为“多努力”。
- 明确建议联系班主任、辅导员、学校心理中心等支持渠道。

建议话术：

> 我注意到你描述的情况已经不只是普通的规划问题。你现在更需要的是身边人的实际支持。建议你尽快联系辅导员、班主任或学校心理健康教育中心。我也建议暂时把考试、就业等目标往后放，先把睡眠、情绪和基本节奏稳定下来。

## 4. 常见支持资源占位

- 班主任 / 辅导员
- 学校心理健康教育中心
- 校医院
- 学生资助管理中心
- 就业指导中心
- 教务处 / 学院教务办公室
