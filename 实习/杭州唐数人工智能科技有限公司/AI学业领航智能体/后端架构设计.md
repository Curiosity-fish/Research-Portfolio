## 一、架构概览

### 1.1 技术栈选型

**后端框架：** Spring Boot 3.x  
**数据库：** MySQL 8.0（主库）+ Redis 7.x（缓存）  
**ORM 框架：** MyBatis-Plus  
**API 文档：** Knife4j（Swagger 增强）  
**认证鉴权：** Spring Security + JWT  
**AI 接入：** 通义千问 / 文心一言 / GPT-4（可配置）  
**消息队列：** RabbitMQ（异步任务、通知推送）  
**任务调度：** XXL-Job（数据同步、报告生成）  
**日志：** SLF4J + Logback  
**监控：** Spring Boot Actuator + Prometheus + Grafana

**推荐理由：**
- Spring Boot 生态成熟，开发效率高
- MyBatis-Plus 简化 CRUD，支持代码生成
- Redis 缓存热点数据，降低数据库压力
- JWT 无状态认证，适合分布式部署

## 二、数据库设计

### 2.1 核心表结构

#### 2.1.1 用户与角色表

**user（用户表）**
```sql
CREATE TABLE `user` (
  `id` BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '用户ID',
  `username` VARCHAR(50) NOT NULL UNIQUE COMMENT '登录账号',
  `password` VARCHAR(255) NOT NULL COMMENT '密码（BCrypt加密）',
  `real_name` VARCHAR(50) COMMENT '真实姓名',
  `role` ENUM('student','teacher','course_teacher','department','dean') NOT NULL COMMENT '角色',
  `email` VARCHAR(100) COMMENT '邮箱',
  `phone` VARCHAR(20) COMMENT '手机号',
  `avatar` VARCHAR(255) COMMENT '头像URL',
  `status` TINYINT DEFAULT 1 COMMENT '状态：0禁用 1启用',
  `created_at` DATETIME DEFAULT CURRENT_TIMESTAMP,
  `updated_at` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  INDEX `idx_username` (`username`),
  INDEX `idx_role` (`role`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户表';
```

**student（学生表）**
```sql
CREATE TABLE `student` (
  `id` BIGINT PRIMARY KEY AUTO_INCREMENT,
  `user_id` BIGINT NOT NULL COMMENT '关联user表',
  `student_id` VARCHAR(20) NOT NULL UNIQUE COMMENT '学号',
  `name` VARCHAR(50) NOT NULL COMMENT '姓名',
  `gender` ENUM('male','female') COMMENT '性别',
  `grade` INT COMMENT '年级（如2021）',
  `class_id` BIGINT COMMENT '班级ID',
  `major_id` BIGINT COMMENT '专业ID',
  `department_id` BIGINT COMMENT '学院ID',
  `enrollment_date` DATE COMMENT '入学日期',
  `gpa` DECIMAL(3,2) COMMENT '当前GPA',
  `total_credits` DECIMAL(5,1) DEFAULT 0 COMMENT '已修学分',
  `required_credits` DECIMAL(5,1) COMMENT '需修学分',
  `alert_level` ENUM('none','yellow','orange','red') DEFAULT 'none' COMMENT '预警等级',
  `created_at` DATETIME DEFAULT CURRENT_TIMESTAMP,
  `updated_at` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  FOREIGN KEY (`user_id`) REFERENCES `user`(`id`),
  INDEX `idx_student_id` (`student_id`),
  INDEX `idx_class_major` (`class_id`, `major_id`),
  INDEX `idx_grade` (`grade`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='学生表';
```

**teacher（教师表）**

#### 2.1.2 课程与成绩表

**course（课程表）**
```sql
CREATE TABLE `course` (

  `name` VARCHAR(100) NOT NULL COMMENT '课程名称',
```

**course_class（课程班级表 - 一门课多个班）**
```sql
CREATE TABLE `course_class` (
  `id` BIGINT PRIMARY KEY AUTO_INCREMENT,
  `course_id` BIGINT NOT NULL COMMENT '课程ID',
  `term` VARCHAR(20) NOT NULL COMMENT '学期（如2024-上）',
  `class_name` VARCHAR(50) COMMENT '班级名称（如A班）',

  FOREIGN KEY (`teacher_id`) REFERENCES `teacher`(`id`),
  INDEX `idx_term` (`term`),
  INDEX `idx_teacher` (`teacher_id`)

```

**grade（成绩表）**
```sql
CREATE TABLE `grade` (
  `id` BIGINT PRIMARY KEY AUTO_INCREMENT,
  `student_id` BIGINT NOT NULL COMMENT '学生ID',
  `course_class_id` BIGINT NOT NULL COMMENT '课程班级ID',
  `score` DECIMAL(5,2) COMMENT '成绩（0-100）',
  `grade_point` DECIMAL(3,2) COMMENT '绩点（0-5.0）',
  `status` ENUM('pending','passed','failed','retake') DEFAULT 'pending',
  `term` VARCHAR(20) NOT NULL COMMENT '学期',
  `exam_date` DATE COMMENT '考试日期',
  `remark` VARCHAR(255) COMMENT '备注',
  `created_at` DATETIME DEFAULT CURRENT_TIMESTAMP,
  `updated_at` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  FOREIGN KEY (`student_id`) REFERENCES `student`(`id`),
  FOREIGN KEY (`course_class_id`) REFERENCES `course_class`(`id`),
  INDEX `idx_student_term` (`student_id`, `term`),
  INDEX `idx_course_class` (`course_class_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='成绩表';
```

#### 2.1.3 预警表

**alert（预警记录表）**
```sql
CREATE TABLE `alert` (

  `handler_id` BIGINT COMMENT '处理人ID',

  INDEX `idx_student` (`student_id`),
  INDEX `idx_level_status` (`level`, `status`),
  INDEX `idx_trigger_date` (`trigger_date`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='预警记录表';
```

### 2.2 数据字典

**预警等级定义：**
- `yellow`：黄色预警 - GPA 2.3-2.5 或成绩边缘波动
- `orange`：橙色预警 - GPA 2.0-2.3 或多门挂科风险
- `red`：红色预警 - GPA < 2.0 或严重出勤问题

**成绩状态：**
- `pending`：待出分
- `passed`：通过
- `failed`：挂科
- `retake`：重修

**课程类型：**
- `required`：必修课
- `elective`：选修课
- `public`：公共课

## 三、API 接口设计

### 3.1 接口规范

**RESTful 风格 + 统一响应格式**

**请求头：**
```
Authorization: Bearer <JWT_TOKEN>
Content-Type: application/json
```

**响应格式：**
```json
{
  "code": 200,
  "message": "success",
  "data": { ... },
  "timestamp": 1703001234567
}
```

**错误码定义：**
- `200`：成功
- `400`：请求参数错误
- `401`：未授权
- `403`：无权限
- `404`：资源不存在
- `500`：服务器内部错误

### 4.1 GPA 计算规则

**绩点映射表（百分制转5分制）：**
| 分数区间 | 绩点 | 等级 |
|---------|------|------|
| 90-100 | 4.0-5.0 | A |
| 80-89 | 3.0-3.9 | B |
| 70-79 | 2.0-2.9 | C |
| 60-69 | 1.0-1.9 | D |
| <60 | 0 | F |

**GPA 计算公式：**
```
GPA = Σ(课程绩点 × 课程学分) / Σ(课程学分)
```

**Java 实现示例：**
```java
public BigDecimal calculateGPA(List<Grade> grades) {
    BigDecimal totalPoints = BigDecimal.ZERO;
    BigDecimal totalCredits = BigDecimal.ZERO;
    
    for (Grade grade : grades) {
        if (grade.getStatus() == GradeStatus.PASSED || 
            grade.getStatus() == GradeStatus.FAILED) {
            BigDecimal gradePoint = scoreToGradePoint(grade.getScore());
            BigDecimal credits = grade.getCourse().getCredits();
            totalPoints = totalPoints.add(gradePoint.multiply(credits));
            totalCredits = totalCredits.add(credits);
        }
    }
    
    return totalCredits.compareTo(BigDecimal.ZERO) == 0 ? 
           BigDecimal.ZERO : 
           totalPoints.divide(totalCredits, 2, RoundingMode.HALF_UP);
}

private BigDecimal scoreToGradePoint(BigDecimal score) {
    if (score.compareTo(new BigDecimal("90")) >= 0) {
        return new BigDecimal("4.0").add(
            score.subtract(new BigDecimal("90"))
                .divide(new BigDecimal("10"), 2, RoundingMode.HALF_UP)
        );
    } else if (score.compareTo(new BigDecimal("80")) >= 0) {
        return new BigDecimal("3.0").add(
            score.subtract(new BigDecimal("80"))
                .divide(new BigDecimal("10"), 2, RoundingMode.HALF_UP)
        );
    } else if (score.compareTo(new BigDecimal("70")) >= 0) {
        return new BigDecimal("2.0").add(
            score.subtract(new BigDecimal("70"))
                .divide(new BigDecimal("10"), 2, RoundingMode.HALF_UP)
        );
    } else if (score.compareTo(new BigDecimal("60")) >= 0) {
        return new BigDecimal("1.0").add(
            score.subtract(new BigDecimal("60"))
                .divide(new BigDecimal("10"), 2, RoundingMode.HALF_UP)
        );
    } else {
        return BigDecimal.ZERO;
    }
}
```

### 4.2 预警规则引擎

**预警触发条件：**

| 预警等级 | 触发条件 |
|---------|---------|
| 红色 | GPA < 2.0 **或** 缺勤 > 5次 **或** 连续2学期挂科≥3门 |
| 橙色 | 2.0 ≤ GPA < 2.3 **或** 单学期挂科≥2门 |
| 黄色 | 2.3 ≤ GPA < 2.5 **或** 成绩波动大（单学期GPA下降≥0.5） |

**规则引擎实现：**
```java
@Service
public class AlertRuleEngine {
    
    public AlertLevel evaluateAlert(Student student, List<Grade> recentGrades) {
        BigDecimal gpa = student.getGpa();
        int absences = getAbsences(student);
        int failedCount = countFailedCourses(recentGrades);
        
        // 红色预警
        if (gpa.compareTo(new BigDecimal("2.0")) < 0 || 
            absences > 5 || 
            hasConsecutiveFailures(student)) {
            return AlertLevel.RED;
        }
        
        // 橙色预警
        if ((gpa.compareTo(new BigDecimal("2.0")) >= 0 && 
             gpa.compareTo(new BigDecimal("2.3")) < 0) || 
            failedCount >= 2) {
            return AlertLevel.ORANGE;
        }
        
        // 黄色预警
        if ((gpa.compareTo(new BigDecimal("2.3")) >= 0 && 
             gpa.compareTo(new BigDecimal("2.5")) < 0) || 
            hasLargeGpaFluctuation(student)) {
            return AlertLevel.YELLOW;
        }
        
        return AlertLevel.NONE;
    }
    
    private boolean hasConsecutiveFailures(Student student) {
        // 检查连续2学期挂科情况
        List<String> recentTerms = getRecentTerms(2);
        for (String term : recentTerms) {
            int failedCount = gradeMapper.countFailedCourses(student.getId(), term);
            if (failedCount < 3) {
                return false;
            }
        }
        return true;
    }
    
    private boolean hasLargeGpaFluctuation(Student student) {
        List<BigDecimal> recentGpas = getRecentGpas(student.getId(), 2);
        if (recentGpas.size() < 2) return false;
        
        BigDecimal diff = recentGpas.get(0).subtract(recentGpas.get(1));
        return diff.abs().compareTo(new BigDecimal("0.5")) >= 0;
    }
}
```

### 4.3 课程健康度评分

**评分维度：**
1. **通过率**（40%权重）：及格人数/总人数
2. **平均分**（30%权重）：班级平均成绩
3. **高分率**（15%权重）：≥85分人数/总人数
4. **不及格率**（15%权重）：<60分人数/总人数（负向）

**健康度计算公式：**
```
健康度 = 通过率×40 + (平均分/100)×30 + 高分率×15 - 不及格率×15
```

**风险判定：**
- 健康度 ≥ 85：正常（绿色）
- 75 ≤ 健康度 < 85：需关注（橙色）
- 健康度 < 75：高风险（红色）

**Java 实现：**
```java
public CourseHealthScore calculateCourseHealth(Long courseClassId) {
    List<Grade> grades = gradeMapper.selectByCourseClass(courseClassId);
    int total = grades.size();
    
    if (total == 0) {
        return new CourseHealthScore(0, "无数据");
    }
    
    long passedCount = grades.stream()
        .filter(g -> g.getScore().compareTo(new BigDecimal("60")) >= 0)
        .count();
    
    long highScoreCount = grades.stream()
        .filter(g -> g.getScore().compareTo(new BigDecimal("85")) >= 0)
        .count();
    
    long failedCount = grades.stream()
        .filter(g -> g.getScore().compareTo(new BigDecimal("60")) < 0)
        .count();
    
    BigDecimal avgScore = grades.stream()
        .map(Grade::getScore)
        .reduce(BigDecimal.ZERO, BigDecimal::add)
        .divide(new BigDecimal(total), 2, RoundingMode.HALF_UP);
    
    double passRate = (double) passedCount / total;
    double highRate = (double) highScoreCount / total;
    double failRate = (double) failedCount / total;
    
    double healthScore = passRate * 40 + (avgScore.doubleValue() / 100) * 30 
                        + highRate * 15 - failRate * 15;
    
    String level = healthScore >= 85 ? "正常" : 
                   healthScore >= 75 ? "需关注" : "高风险";
    
    return new CourseHealthScore((int) healthScore, level);
}
```

```java
@Component
public class JwtAuthenticationFilter extends OncePerRequestFilter {
    
    @Autowired
    private JwtTokenProvider tokenProvider;
    
    @Override
    protected void doFilterInternal(HttpServletRequest request, 
                                   HttpServletResponse response, 
                                   FilterChain chain) 
            throws ServletException, IOException {
        
        String token = getTokenFromRequest(request);
        
        if (token != null && tokenProvider.validateToken(token)) {
            Long userId = tokenProvider.getUserIdFromToken(token);
            String role = tokenProvider.getRoleFromToken(token);
            
            UserDetails userDetails = loadUserDetails(userId, role);
            UsernamePasswordAuthenticationToken auth = 
                new UsernamePasswordAuthenticationToken(
                    userDetails, null, userDetails.getAuthorities()
                );
            
            SecurityContextHolder.getContext().setAuthentication(auth);
        }
        
        chain.doFilter(request, response);
    }
    
    private String getTokenFromRequest(HttpServletRequest request) {
        String bearerToken = request.getHeader("Authorization");
        if (StringUtils.hasText(bearerToken) && bearerToken.startsWith("Bearer ")) {
            return bearerToken.substring(7);
```

```java
public class DataPermissionInterceptor implements InnerInterceptor {
    
    @Override
    public void beforeQuery(Executor executor, MappedStatement ms, 
                           Object parameter, RowBounds rowBounds, 
                           ResultHandler resultHandler, BoundSql boundSql) {

            case "teacher":
                Long classId = getTeacherClassId(userId);
                sql = addCondition(sql, "student.class_id = " + classId);
                break;
            case "course_teacher":
                sql = addCourseTeacherCondition(sql, userId);
                break;
            case "department":
                Long majorId = getDepartmentMajorId(userId);
                sql = addCondition(sql, "student.major_id = " + majorId);
                break;
            // dean 角色无需过滤
        }
        
        // 重新设置SQL
        Field field = boundSql.getClass().getDeclaredField("sql");
        field.setAccessible(true);
        field.set(boundSql, sql);
    }
}
```

```java
@Component
public class XssFilter implements Filter {
    
    @Override
    public void doFilter(ServletRequest request, ServletResponse response, 
                        FilterChain chain) throws IOException, ServletException {
        XssHttpServletRequestWrapper wrappedRequest = 
            new XssHttpServletRequestWrapper((HttpServletRequest) request);
        chain.doFilter(wrappedRequest, response);
    }
}

public class XssHttpServletRequestWrapper extends HttpServletRequestWrapper {
    
    @Override
    public String getParameter(String name) {
        String value = super.getParameter(name);
        return cleanXss(value);
    }
    
    private String cleanXss(String value) {
        if (value == null) return null;
        return value.replaceAll("<", "&lt;")
                    .replaceAll(">", "&gt;")
                    .replaceAll("\"", "&quot;")
                    .replaceAll("'", "&#x27;");
    }
}
```

**接口限流（Redis + Lua）：**
```java
@Aspect
@Component
public class RateLimitAspect {
    
    @Autowired
    private RedisTemplate<String, Long> redisTemplate;
    
    @Around("@annotation(rateLimit)")
    public Object around(ProceedingJoinPoint point, RateLimit rateLimit) 
            throws Throwable {
        
        String key = "rate_limit:" + getClientIp() + ":" + 
                     point.getSignature().toShortString();
        
        Long count = redisTemplate.opsForValue().increment(key);
        if (count == 1) {
            redisTemplate.expire(key, rateLimit.period(), TimeUnit.SECONDS);
        }
        
        if (count > rateLimit.limit()) {
            throw new RateLimitException("请求过于频繁，请稍后再试");
        }
        
        return point.proceed();
    }
}

@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface RateLimit {
    int limit() default 10;  // 次数
    int period() default 60; // 时间窗口（秒）
}
```
